This uses the Leaflet JavaScript library with a static map image, the NPS park brochure for Gettysburg National Park. Pins on the map match the stops on the vehicle tour and have links to wikipedia articles. There is a link to a basic leaflet map, made with the Leaflet Quickstart tutorial, that is centered on the "no-man's land" of the Gettysburg battlefield and allows linking to the matching Google maps image when clicking on the map.

The park brochure was downloaded from the Library of Congress site: http://hdl.loc.gov/loc.gmd/g3822g.cw0352500
